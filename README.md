# link-shortner

## ⚙️ Setup & Run

### 1. Clone the repo

```bash
git clone https://gitlab.12devs.com/training/internship/2025-interns/gnunko/link-shortner
cd link-shortner
```

### 2. Install dependencies

```bash
npm install
```

### 3. Create .env files

See example below for: `.env`.

### 6. Start the app

```bash
npm run dev
```

For production:

```bash
npm run build
npm run start:prod
```
